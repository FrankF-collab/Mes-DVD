# Ma collection de DVD

Application web (PWA) pour gérer une collection de DVD : ajout, modification, recherche, scan de code-barre, export/import Excel, installable sur mobile.

## Utilisation

Ouvre `index.html` dans un navigateur, ou héberge ce dossier avec GitHub Pages pour y accéder depuis n'importe quel appareil avec une vraie adresse web (https://...github.io/...), ce qui permet notamment l'accès à l'appareil photo pour le scan de code-barre (nécessite un vrai domaine, pas un simple fichier local).
